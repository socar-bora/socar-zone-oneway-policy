# 쏘카 웹 편도 지도 UX 정책 프로토타입

쏘카존 편도(다른 곳에 반납)·배달 편도 확정 후 지도 카메라 정책을 확인하는 프로토타입입니다.
(최종 결정 2026-11-03 — 기본 뷰는 **2안: 거리와 무관하게 항상 한 화면 핏**)

- 반납 확정 후에는 지도를 자유롭게 움직일 수 있고, 움직여도 목록을 재조회하지 않음 (목록 변경은 대여 위치 검색뿐)
- 기본 뷰: 목록 쪽(쏘카존 클러스터 / 배달 위치) ↔ 반납 위치를 **항상 한 화면에 핏** — 서울 ↔ 부산처럼 멀어도 동일. 멀어서 존 핀이 겹치면 `쏘카존 N` 클러스터 마커로 묶임(누르면 확대)
- 탐색 중 한쪽이 화면 밖으로 나가면(확대·이동) 지도 이동 버튼(반납 / 쏘카존 / 배달 위치 보기) 노출, 둘 다 밖이면 목록 쪽 우선, 화살표는 목표 방향
- 반납 핀 편집 후 확정이면 기본 뷰 재판정, 취소면 카메라 유지
- 모바일 바텀시트 35% / 55% / 전체
- `1안 · 먼 거리는 쏘카존부터`는 구현이 어려울 때의 대안(핀 간격 44px 미만이면 쏘카존부터 보여주고 `반납 위치 보기` 버튼) — 하단 **기본 뷰** 토글로 비교할 수 있음

하단 옵션 바의 **편도 예시**(이태원역 반납 · 부산역 반납 · 배달 편도)로 바로 확인할 수 있습니다.
`index.html` 하나와 `assets/` 폴더로 구성되어 GitHub Pages에서 그대로 열립니다.
